# Deferred

**Every item here is a decision that has not been made, or work knowingly not done.** Each
one is marked at the place it bites — `TODO` for an open decision, `PLANNED` for agreed work —
so `grep -rnE 'TODO|PLANNED'` finds it in the code or in the system note that owns it. This file is the INDEX — it says what the question is and where the
real write-up lives; it never restates the write-up.

Compiled 2026-08-29; answered questions last moved to §2 on 2026-09-24; §2 re-checked against the code on 2026-09-28. The convention behind it is `~/.claude/CLAUDE.md` §13.1.

```
grep -rnE 'TODO|PLANNED' scripts/ tools/ tests/ gdd/
```
