# Mission 3 — Base, training and economy

Status: draft. The player gets a base for the first time and learns to place it, fund it and produce from it.

## Teaches

- The command centre drop: scouting longer delays income, so placement is a tradeoff
- The two free extractor drops, then building extractors on extraction sites and lithium ponds
- Training units and the global production queue (one unit per structure at a time)
- Rally points

## Reinforces

Counters and control groups from mission 2, now with units the player chose to build.

## Player fantasy

Going from scraping by to running an operation.

## Narrative justification

Having held the town, the force is authorised to set up a forward base. Command leaves the drop site to the commander on the ground, which is why the player scouts before committing.

## Setup

- Starting force: the mission 2 survivors plus builders; command centre drop unused
- Map: a few candidate drop sites with different tradeoffs (close to sites vs defensible vs near a pond)
- Enemies: light probing early, then a timed attack wave once the base is up

## Objectives

1. Drop the command centre
2. Place both free extractors, then build one more on an extraction site
3. Train an army and survive the attack wave

## Teaching beats

- **Introduce:** drop the command centre with no enemy pressure
- **Develop:** extractors and training, with a hint about the queue
- **Twist:** a lithium pond far from base pays fast but is exposed
- **Conclude:** an attack wave that tests whether the player built the right counters

## Constraints

One faction tech tier at most; no sanctions or dominion yet.
