# Challenge series

Status: draft. Short, optional scenarios, each drilling one skill the [prologue](../01-prologue/README.md) leaves out so as not to overwhelm new players. A challenge has no story arc: it isolates one skill, tests it under time or pressure, and scores the result so players can come back and improve.

## How a challenge differs from a mission

- **One skill per challenge.** It has no narrative justification beyond a line of framing, and its setup removes anything that isn't the skill being drilled.
- **It is scored, not just passed.** Each challenge has a pass condition and a score, such as time, units lost or hit rate, so it rewards replay. How scores display is open.
- **It points at its rules.** Like the mission docs, a challenge links to the system note that defines the skill, and never restates key tables or values that will change.

Every challenge doc uses the same template: Status, Skill, Prerequisites, Drills, Pass and score, Pieces, Scenario file, Open questions.
