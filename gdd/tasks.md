# Skirmish Map Creation
For the sake of game testing, I'd like for you to create skirmish maps for me. I'll have you just make adaptations of some existing RTS maps:
- Maps:
	- C&C Generals Zero Hour: Tournament Desert
	- C&C Generals Zero Hour: Tiny Tactics
- Map adaptation considerations
	- where there exist supplies on the original map, palace deposits
	- where there exist oil derricks, place shelters
	- place the faction start near the canonical starting deposit for the player, but have those deposits already start with mines
	- put some number of neutral buildings in the center of the map, as exists in the original tournament desert
Have a first pass, and I'll review
