Dominion generation method plan for other planned factions:
- Libertarian - build a structure dedicated to dominion generation, where dominion as generated at some rate per surrounding terrain tile which is not occupied by a structure
- Technocratic - build a dedicated structure ontop of a deposit, which will generate dominion over time. Uniquely, the structure will generate a byproduct resource as it generates dominion. If the byproduct reaches a capacity, the structure will stop generating dominion. A faction-specific unit will need to interact with the structure to remove the byproduct and restart dominion generation.
- Marxist - damage non-friendly structures to generate dominion
- Theological - a faction-specific unit will be "tasked" on a shelter indefinitely, and it will passively generate dominion
